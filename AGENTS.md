# Contexto do projeto

Este site faz parte de um exercício de faculdade sobre teste A/B para melhorar a conversão de locações de veículos de alta margem. A versão de controle é https://eduardotadeudealmeida.github.io/LocadoraVeiculos/; este projeto contém a variante em desenvolvimento.
